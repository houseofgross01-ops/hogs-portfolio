HOGS site — how to edit (Sublime)
index.html      -> text, sections, team names/roles
css/style.css   -> colours (top variables), fonts, spacing
js/main.js      -> VIDEOS and WORK lists (titles, tags, links)
images/logo-hogs.png -> replace with your logo (keep the same name, PNG, transparent)
images/team/    -> replace founder.jpg, cmo.jpg, creative-lead.jpg, head-of-production.jpg
                   (same names, portrait 4:5, e.g. 800x1000)
Open index.html in a browser to preview.
